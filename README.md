# HealNex Medi Bazar

**HealNex Medi Bazar** is a modern multi-vendor B2B & B2C medical equipment marketplace designed to connect manufacturers, distributors, hospitals, clinics, diagnostic centers, and healthcare professionals across India.

## Features

* Multi-Vendor Marketplace
* Vendor Registration & Verification
* Customer Registration & Login
* Product Catalog with Categories
* Product Search & Filters
* Shopping Cart & Checkout
* Order Management
* Vendor Dashboard
* Admin Dashboard
* Product Approval System
* Secure Authentication
* Product Reviews & Ratings
* Wishlist
* Offers & Coupons
* Inventory Management
* SEO Optimized
* Dynamic Sitemap Generation
* robots.txt
* Mobile Responsive Design
* Fast Performance

## Tech Stack

## Installation

```bash
git clone https://github.com/yourusername/healnex-medi-bazar.git

cd healnex-medi-bazar

npm install

npm run dev
```

## Build

```bash

```
